Traces

One row per AI turn — where the time went, what was retrieved, and what broke.

Time Correlation id Conversation Channel Total Status

Turn

One turn, as the row recorded it. Nothing here is derived from anything but this row.

Stage durations

How long each stage took — not when it started. The row records durations only, so there are no offsets to lay out. Stages nest, so the bars can sum past the turn total.

Retrieval

Chunk ids and similarity scores. Chunk text is never written to a trace — it lives in knowledge_chunks. Rows marked below floor were retrieved and then discarded.

Prompt provenance

A hash of the final system prompt, the config version it was rendered from, and which precedence branch produced it. The prompt text itself is never stored.

Model

Token counts and latency per call, aggregated across the turn's tool loop.

Tool calls

In execution order, with the tool's own reported outcome — never its output.

Error

Present only on a turn that failed or was aborted.
